# Macro War Room

Cruscotto macro e mappa di situazione costruiti su dati pubblici: FRED e ALFRED (St. Louis Fed), ECB Data Portal, Eurostat, Banca Mondiale, Commissione europea (Weekly Oil Bulletin), indice GPR di Caldara e Iacoviello, Natural Earth. Si rigenera ogni ora da script. Informazione economica, non una raccomandazione di investimento.
